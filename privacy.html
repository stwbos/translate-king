翻译王 (TranslateKing) 隐私政策

更新日期：2026年10月22日

翻译王（TranslateKing）致力于保护用户的个人隐私安全。本扩展程序严格遵守“最小必要权限原则”及 Google Chrome Web Store 开发者计划政策。

1. 数据收集与使用

  • 零个人隐私追踪：翻译王不收集、不存储、不上传您的姓名、电子邮件、浏览历史、密码或任何个人身份信息（PII）。
  • 本地配置保存：您的个性化偏好（如目标语言、界面主题、自定义快捷键等）仅存储在浏览器本地的 chrome.storage 中，绝不上传至任何集中式商业服务器。
  • 翻译请求直连：当您触发翻译时，待翻译的网页文本仅直接发送至您所选定的翻译服务商（如 Google Translate、微软翻译，或您自行配置的大模型 API 接口如 DeepSeek、OpenAI）。翻译王不设立中间服务器截留您的翻译内容。

2. 权限使用说明

  • <all_urls>：仅用于在用户访问的外文网页中提取待翻译正文，并在段落下方向 DOM 注入双语对照译文及视频字幕。
  • storage / unlimitedStorage：用于在本地保存用户的翻译偏好配置、离线词典缓存及生词本数据。
  • offscreen：用于在独立的沙箱环境中运行本地语音合成（TTS）发音及文档解析，确保主浏览页面流畅不卡顿。
  • declarativeNetRequestWithHostAccess：仅在用户启用特定翻译源时，适配翻译请求头以确保跨域翻译请求畅通。

3. 开源与合规

翻译王遵循 GNU GPL-3.0 协议开源，代码透明可查。开源代码仓库位于：https://github.com/stwbos/translate-king。

TranslateKing Privacy Policy

Last updated: October 22, 2026

TranslateKing is committed to protecting your privacy. This browser extension strictly adheres to the principle of data minimization and the Google Chrome Web Store Developer Program Policies.

1. Data Collection and Usage

  • No Personal Tracking: TranslateKing does not collect, store, or transmit your name, email address, browsing history, passwords, or any personally identifiable information (PII).
  • Local Storage Only: Your preferences (target languages, themes, shortcut keys, vocabulary cards) are stored locally using chrome.storage and are never transmitted to any centralized commercial servers.
  • Direct Provider Transmission: When you request translation, only the selected webpage text is transmitted directly to your chosen provider (e.g., Google Translate, Microsoft Translator, or your configured API endpoints such as DeepSeek or OpenAI). TranslateKing does not operate intermediary servers to log or retain your content.

2. Permissions Justification

  • <all_urls>: Required exclusively to detect foreign language text on user-visited webpages and inject inline bilingual translations and video subtitles into the DOM.
  • storage & unlimitedStorage: Used to store user settings, cached translations, and vocabulary records locally on your device.
  • offscreen: Used to manage speech synthesis (TTS) playback and document layout analysis in an isolated sandbox without degrading page performance.
  • declarativeNetRequestWithHostAccess: Modifies network request headers strictly when necessary to route user-directed translation requests to chosen service APIs.

3. Open Source & Transparency

TranslateKing is open source under GNU GPL-3.0. The full source code is publicly inspectable at: https://github.com/stwbos/translate-king.
